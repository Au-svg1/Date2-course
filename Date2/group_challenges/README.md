# Date2 Group Challenge Competition

Seven teams use the same CNEMC-derived Date2 source dataset to build different research-data products. Each team starts at its own `group_xx/START_HERE.md`. Student-facing packages contain unchanged input data, a minimal loading script, a challenge brief, submission templates, and secondary resources.

The competition rewards scientific judgment, transparent decisions, reproducibility, metadata/provenance, AI verification, peer review, and oral defense. It does not reward unexplained code complexity. Instructor-only live challenges and the teaching-quality audit are in `instructor/`.

No source PDF, original Date2 output, or environmental observation should be edited by these activities.
